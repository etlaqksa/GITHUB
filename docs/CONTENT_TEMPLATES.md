# قوالب المحتوى (Phase 3)

## 1) قالب مقال Pillar (عربي/إنجليزي)
**الهدف:** مقال مرجعي طويل يشرح المشكلة، متى تحتاج الخدمة، كيف نعمل، ومعايير التحقق + روابط داخلية لصفحات الخدمات/المدن.

### هيكل مقترح
1. مقدمة المشكلة + لماذا تحدث
2. علامات تستدعي التدخل (Checklist)
3. طرق التشخيص (GPR/ERT/حفر اختبار/قياسات)
4. خيارات المعالجة (حقن/تقوية أساسات/معالجة الفراغات)
5. منهجية التنفيذ (Steps)
6. معايير القبول والتحقق (Validation criteria)
7. أخطاء شائعة وكيف نتجنبها
8. الأسئلة الشائعة (FAQ) + روابط داخلية
9. CTA نهائي: طلب تقييم/طلب خدمة

## 2) قالب Case Study (دراسة حالة)
**الهدف:** تحويل المشاريع إلى قصة واضحة: Problem → Approach → Result → Proof.

### هيكل مقترح
- **المدينة + نوع المنشأة**
- **المشكلة (Problem)**
- **التشخيص (Diagnosis)**
- **المنهجية (Approach)**
- **التنفيذ (Execution)**
- **النتائج (Results)**
  - مؤشرات: استقرار/توقف تشققات/تحسن قيم/تقارير
- **المخرجات (Deliverables)**
- **مدة التنفيذ**
- **CTA**
